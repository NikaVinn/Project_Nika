# Design Prompt — Warm Editorial

Бриф для передачи дизайнеру или фрилансеру, который будет создавать новые экраны, материалы или ассеты для Wardrobe Bureau в уже выбранном визуальном направлении.

## О проекте

Wardrobe Bureau — платформа-подписка на стиль для женщин 25–50 лет, Европа. Пользовательница получает капсульные гардеробы, реальные шопинг-подборки и советы стилиста без цены персонального стилиста. Тон бренда: тёплый, взрослый.

## Название направления: Warm Editorial

Референс ощущения: разворот глянцевого журнала о стиле жизни (Kinfolk, The Gentlewoman, но теплее) — много воздуха, крупная серифная типографика, приглушённая тёплая палитра, никакого неона и "стартаперской" синевы.

## Настроение в трёх словах

**Тёплый. Взрослый. Редакционный.**

Не: минимализм в духе Apple, не яркий "girly" розовый, не корпоративный SaaS, не молодёжный TikTok-стиль.

## Палитра

| Название | HEX | Роль |
|---|---|---|
| Cream | `#FAF8F5` | Основной фон — тёплый, не белый |
| Sand | `#E2D5C3` | Фон секций, карточки |
| Sand Dark | `#C9B99E` | Плейсхолдеры изображений, бордеры, разделители |
| Rose | `#C4877A` | Акцент — надписи-эйброу, курсив, hover-состояния. Используется точечно, не как основной цвет |
| Charcoal | `#1A1A1A` | Основной текст, тёмные секции, фон primary-кнопки. Не чистый чёрный |
| Mid | `#6B6560` | Второстепенный текст, параграфы |
| Light text | `#9E9790` | Подписи, мелкий текст, лейблы плейсхолдеров |
| Burgundy | `#6D2A32` | Фон full-bleed quote-секции |

Правило: фон почти всегда тёплый нейтральный (cream/sand), акцентный rose используется скупо — как курсив в тексте, а не как заливка кнопок или крупных блоков. Burgundy используется только для fullbleed quote-блока, не для других тёмных секций (footer/CTA остаются charcoal).

## Типографика

- **Заголовки:** Cormorant Garamond — серифный, элегантный, лёгкий. Используется только с весом 300 (light) или 400, крупный кегль (48–72px на десктопе), межстрочный интервал плотный (1.05–1.1). Курсив (italic) используется внутри заголовка для смыслового акцента — обычно одно-два слова. Цвет курсива зависит от секции: в hero-заголовке акцентное слово ("finally") — бургунди; в остальных заголовках (section-title, cta-title) курсив остаётся rose.
- **Текст/интерфейс:** DM Sans — гротеск, веса 300/400/500. Основной текст мелкий (14–16px) с щедрым line-height (1.7–1.8) — ощущение "воздуха", неспешного чтения.
- **Лейблы/эйброу:** всё в верхнем регистре, letter-spacing 0.1–0.2em, мелкий кегль (11–13px), цвет rose или mid.

Правило: никогда не смешивать два серифных или два гротескных шрифта. Заголовок — всегда Cormorant, тело — всегда DM Sans.

## Композиция и ритм

- Много пустого пространства: секции с вертикальным паддингом 100–120px.
- Асимметричные 2-колоночные сетки (текст слева/справа, контент напротив) — избегать центрированной симметрии, кроме full-bleed цитаты.
- Тонкие разделители (1px, цвет sand) между блоками вместо теней и радиусов.
- Никаких скруглений (border-radius), никаких теней (box-shadow) — плоские, чёткие прямоугольники, как печатная полоса.
- Изображения — плейсхолдеры тёплого sand-dark тона с подписью капсом мелким шрифтом, пока нет реальной съёмки.

## Компоненты

- **Кнопки:** прямоугольные, без скруглений. Primary — заливка charcoal, текст cream, hover → rose. Ghost/outline — прозрачный фон, только нижняя или полная граница, hover меняет цвет текста/бордера на rose.
- **Карточки:** плоские, фон sand или cream, без теней, разделены тонкими линиями или узким gap (2–3px) между собой — эффект "сетки в журнале", а не отдельных плавающих карточек.
- **Тёмные секции (цитаты, акценты):** сплошной charcoal-фон, крупный курсивный Cormorant текст на cream — используются как "передышка" между светлыми секциями.

## Тон голоса (для копирайта, если дизайнер пишет плейсхолдер-текст)

Прямой, честный, без超-мотивационных лозунгов. Короткие фразы. Обращение на "ты"/неформальное "you". Специфика вместо общих слов ("Hours lost searching for the right outfit" вместо "Feel confident every day").

## Чего избегать

- Ярких/неоновых цветов, градиентов
- Скруглённых углов и теней
- Sans-serif заголовков
- Плотной "корпоративной" сетки без воздуха
- Стоковых "улыбающихся команд" — изображения должны быть редакционными, life-style, естественный свет

## Структура страницы (порядок секций)

Лендинг строится как редакционный разворот — секции идут в строгом порядке, каждая решает одну коммуникационную задачу и передаёт эстафету следующей:

1. **Nav** — фикс. шапка: логотип слева, ссылки About / Plans / Contact / FAQ по центру/справа, одна CTA-кнопка справа.
2. **Hero** — 2 колонки: слева заголовок + подзаголовок + 2 кнопки (primary + ghost), справа — карусель из 5 изображений одинакового размера с горизонтальной прокруткой (свайп/скролл вправо-влево). Задача: с первого экрана объяснить, что это и для кого, без скролла.
3. **Problem Validation** — слева короткий заголовок секции, справа — 4 пронумерованных пункта боли ("01–04"), каждый с жирным заголовком-фразой и пояснением. Задача: читательница узнаёт себя.
4. **Quote** — full-bleed секция на бургунди-фоне, одна курсивная цитата-обещание бренда, без подписи атрибуции. Задача: эмоциональная передышка + формулировка ключевого обещания.
5. **Product Deep-Dive** — заголовок секции слева; справа — intro-абзац крупным курсивным Cormorant (24px, не обычный body-текст) и под ним карусель из 3 изображений с горизонтальной прокруткой. Ниже — 2×2 сетка карточек-категорий продукта (иконка + заголовок + список из 3 пунктов). Задача: показать, что внутри подписки.
6. **Objections** — секция на sand-фоне, заголовок + 2×2 сетка вопрос/ответ (курсивный вопрос от лица клиента + прямой ответ). Задача: снять возражения до цены.
7. **Pricing** — слева intro-текст с объяснением разницы тарифов, справа — стек из 2 карточек тарифов (Basic обычная, Premium — инвертированная тёмная, выделенная). Задача: понятный выбор без скрытых условий.
8. **CTA** — 2 колонки: изображение слева, текст+кнопки справа (primary + outline) + строка доверия (trust line: гарантии/условия). Задача: финальный явный призыв к действию.
9. **Secondary CTA** — узкая центрированная секция на sand-фоне для тех, кто не готов платить — альтернативное низкопороговое действие (бесплатный канал/рассылка).
10. **FAQ** — заголовок + 2-колоночная сетка вопрос/ответ (обычный текст, не курсив, в отличие от Objections).
11. **Footer** — тёмная секция: лого, служебные ссылки (Privacy/Terms/Contact/соцсети), копирайт.

Правило порядка: эмоция → проблема → обещание → продукт → возражения → цена → действие → альтернатива → справка → низ. Не переставлять Pricing выше Product/Objections — цена должна идти после того, как ценность объяснена и возражения сняты.

## Наполнение и текст (контент-гайд)

- **Заголовки секций** — всегда 2 строки, вторая строка (или последние 1-2 слова) — курсивом, это несёт главный смысловой акцент. Пример: "Everything you need / *to dress with intention.*"
- **Эйброу над заголовком** — короткая фраза-предисловие капсом, задаёт контекст перед заголовком ("Sound familiar?", "Before you ask", "Plans").
- **Тексты пунктов (problem/objections/faq)** — короткий тезис жирным + 1 короткое пояснительное предложение обычным весом. Не больше 2 предложений на пункт.
- **Тон:** прямая речь, конкретика вместо общих обещаний, без超-мотивационных клише ("измени свою жизнь"). Обращение неформальное ("you"/"ты").
- **Цифры и факты** — конкретные (€19/month, 1.5h personal consultation), не расплывчатые ("доступная цена", "быстрая консультация").
- **CTA-копирайт** — кнопка всегда содержит конкретное действие + цену/условие там, где уместно ("Start for €19 / month"), а не общее "Get Started" (кроме nav, где это ок для компактности).
- **Trust line** под финальным CTA — короткая строка через " · " с ключевыми гарантиями (доступ/отмена/без скрытых платежей).
