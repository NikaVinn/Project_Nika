## How to Use This File

Each assumption has a **status** that updates as evidence comes in:
- 🔴 **Unvalidated** — we're betting on this being true
- 🟡 **Partially validated** — some evidence, not conclusive
- 🟢 **Validated** — confirmed with real data
- ❌ **Invalidated** — assumption was wrong, pivot needed
