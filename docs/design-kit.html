Spacing

Секции живут на крупном ритме. Между блоками внутри секции — узкий gap (3px) создаёт эффект печатной сетки.

120px — section padding-y
80px — grid column gap
60px — section padding-x
52px — hero title → actions
32px — heading → body
24px — objections grid gap
3px — card / image grid gap

Buttons

Без скруглений и теней. Три варианта: primary (заливка), ghost (подчёркивание), outline (обводка).

.btn-primary — charcoal fill → hover rose
.btn-ghost — underline only → hover rose
.btn-outline — bordered → hover fill charcoal
.btn-outline on dark bg
