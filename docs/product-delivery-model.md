# Product Delivery Model: Telegram Channel + Bot + Payments
**Product:** Style Subscription Platform  
**Stage:** Notes / Early Planning  
**Date:** June 2026  
**Status:** 📝 Raw notes — not yet validated

---

## Concept

Telegram-канал + бот + Stripe/PayPal/Przelewy24 + автоматический доступ по тарифу.

---

## Тарифы

### BASIC
Закрытый канал/чат со всеми материалами:
- Живые обзоры 3 раза в неделю
- Капсулы Zara, H&M, COS, Massimo Dutti, Mango, Lux
- Подборки масс-маркет / мидл / люкс
- Обзоры люкса
- Гайды со ссылками

### PREMIUM
Всё из BASIC + 1 раз в месяц 2-часовая индивидуальная консультация.

---

## Как это работает технически

1. Создаёшь закрытый Telegram-канал и (опционально) отдельный чат
2. Создаёшь Telegram-бота через BotFather
3. Делаешь лендинг с тарифами: BASIC / PREMIUM
4. Подключаешь оплату через Stripe Checkout или другой сервис подписок
5. После оплаты бот автоматически выдаёт invite-link в нужный канал
6. Если подписка не оплачена или отменена — бот удаляет пользователя из канала
7. Для PREMIUM бот дополнительно открывает форму записи на консультацию

> Telegram Bot API позволяет ботам управлять invite-ссылками, включая subscription invite links, если бот является администратором канала.

---

## Логика тарифов в базе данных

```sql
users
  - telegram_id
  - email
  - plan: basic / premium
  - subscription_status: active / canceled / past_due
  - subscription_end
  - consultation_used_this_month: true / false
```

**Stripe webhooks:**
- `checkout.session.completed` → бот активирует доступ
- `customer.subscription.deleted` или неоплата → доступ убирается

---

## Что автоматизирует бот

- Принимает оплату
- Выдаёт доступ
- Показывает тариф
- Напоминает о продлении
- Удаляет при неоплате
- Даёт PREMIUM-клиенту ссылку на запись
- Отправляет ежемесячное напоминание: «Запишитесь на консультацию»

> Контент лучше публиковать вручную — стиль, подборки и ссылки требуют твоего вкуса.

## Рекомендуемый путь

**Сначала — быстро проверить спрос:**
1. Telegram-канал BASIC
2. Отдельный Telegram-канал/чат PREMIUM
3. Лендинг с двумя кнопками оплаты (Stripe / PayPal / Przelewy24)
4. После оплаты — автоматическая выдача ссылки через сервис подписок или простой бот
5. PREMIUM — запись через Calendly / Google Calendar

**Потом — когда появятся первые платящие участницы:**
Делать полноценный кастомный бот.

## Тексты тарифов (черновик)

**BASIC — закрытый стильный клуб**  
Для тех, кто хочет регулярно получать готовые капсулы, обзоры брендов и понятные ссылки на актуальные вещи.

**PREMIUM — клуб + личный разбор**  
Для тех, кто хочет не только получать подборки, но и один раз в месяц работать лично: разобрать гардероб, фигуру, сложности и получить индивидуальные рекомендации.
